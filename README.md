# クオンツ実況

相場を予測して、仮想で売買し、その記録をすべて公開するサイト。
本番は **https://ann1678.com/** で動いている。

**予測は結果が出る前にコミットする。** このリポジトリの履歴が、後から書き換えていないことの証明になる。
だから公開リポジトリにしてある。

---

## 何が動いているか

```
GitHub Actions（毎時05分 UTC）
  1. engine/run.py      相場を取る → 判定 → 手仕舞い → 予測 → 集計
  2. data/ をコミット   ← ここが証拠。追記だけで、書き換えない
  3. サイトを組む       Astro でビルド
  4. deploy ブランチへ置き換える（履歴は毎回捨てる。1コミットだけ）
        ↓
Xserver（5分ごとの cron: ~/site-pull.sh）
  5. deploy ブランチを取りに行き、~/ann1678.com/public_html へ反映する
```

**GitHubに鍵を預けていない。** サーバーが公開リポジトリを取りに行くだけなので、
どこにも本番の鍵を置かずに済んでいる。

| 何 | どこ |
|---|---|
| 予測エンジン | `engine/`（Python・requests だけ） |
| サイト | `src/`（Astro 7・静的） |
| 手記 | `content/posts/`（Sveltia CMS で書く。入口は `/admin/`） |
| 記録 | `data/`（**Actions が書く。手で触らない**） |
| サーバー設定 | `deploy/htaccess`（旧URLの転送もここ） |

## 記録の決まり（崩すと、このサイトの意味が消える）

1. **`data/*.jsonl` は追記だけ。** 予測・結果・売買を後から書き換えない
2. **予測は結果より先に書く。** `run.py` は判定してから予測する順番で組んである
3. **バックテストと事前公開の記録を混ぜない。** `backtest.json` は別ファイルで、ページでも別の場所に出す
4. **モデルを変えたら `strategy.py` の `MODEL` の名前も変える。** 変えないと違うやり方の成績が同じ欄に混ざる
5. **パラメータを後から成績のいい値へ寄せない。** 寄せた時点で、その成績は過去への当てはめになる

## 手で動かすとき

```bash
# エンジンを1回まわす（data/ が変わる）
/Users/i2/.pyenv/versions/3.11.4/bin/python3 engine/run.py

# 過去への当てはめを取り直す
/Users/i2/.pyenv/versions/3.11.4/bin/python3 engine/backtest.py

# 手元で見る
npx astro dev

# 本番へ直接送る（ふだんは要らない。Actionsが配る）
./scripts/deploy.sh '~/ann1678.com/public_html'
```

⚠ **手元で編集する前に必ず `git pull --rebase`。** Actionsが毎時 `data/` をコミットするので、
そのままpushすると必ず弾かれる。

## 見張り

| 何 | どこ | 何を見ているか |
|---|---|---|
| 死活監視（内側） | サーバー cron 10分ごと `~/care/monitor.sh` | 200を返すか／`ann-render-ok` の印が本文にあるか |
| 死活監視（外側） | Actions の `alive` ジョブ（毎時） | 同じことをGitHubの機械から見る。サーバーごと落ちた沈黙を捕まえる |
| 配信 | サーバー cron 5分ごと `~/site-pull.sh` | ログは `~/site-pull.log` |

⚠ **`ann-render-ok` の印を消さない。** `src/layouts/Base.astro` のフッターに入っている。消すと監視が鳴る。
⚠ **検査を本業の前に置かない。** 2026-09-08に外形チェックを記録より前に置いて、
   チェックが1回タイムアウトしただけでその回の予測が保存されなかった。検査は最後の別ジョブにしてある。

## 止めたいとき

```bash
# 予測を止める：Actions の engine.yml を無効化（GitHubの画面から）
# 配信を止める：サーバーの cron から site-pull.sh の行を消す
# サイトごと戻す：旧WordPressは ~/ann1678.com/public_html_wp_20260908 に残してある
```

## 経緯

2026-09-08に、株式会社ANNのAIコンサルティングのサイト（WordPress）から入れ替えた。
旧サイトの中身は事業ごと株式会社ドラフトへ移してあるので、旧URLは corp.clubd.co.jp の同じ道へ転送している。
**旧WordPressは削除していない。**サーバーの `~/ann1678.com/public_html_wp_20260908` にそのまま置いてある。
控えは `~/backup/ann-wp-20260908-2013/`（DB 954KB・ファイル 106MB）にもある。

## これは投資の助言ではない

特定の銘柄の売買を勧めるものではない。金融商品取引法にいう投資助言・代理業の登録は受けていない。
書いてあるのは、自分の仮説を試して数えた結果だけ。
