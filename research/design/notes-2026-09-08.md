## 確かめた事実
- **bitbank candlestick API の日付(YYYYMMDD)は UTC 日。** 実測: /btc_jpy/candlestick/1hour/20240908 の先頭 ts=1725753600000 = 2024-09-08T00:00Z。
  未来日(20260909 を 2026-09-08T13:47Z に要求)は HTTP 404 {"success":0,"data":{"code":10000}}。
  → market.candles() は `datetime.now(JST).date()` で「今日」を作るので、**JST 00:00〜09:00 の間は存在しない日を要求して MarketError で落ちる**。
    run.py は毎時走るので、毎日 00:05〜08:05 JST の9回が失敗し予測が残らない見込み。backtest.yml の月曜05:20 JSTも同じ窓。
- 1時間足は少なくとも 2019年まで遡れる(btc_jpy/eth_jpy)。1リクエスト 0.1〜0.25秒。4hour/1day 等は YYYY 指定。
- bitbank 手数料(2026-09 時点, 公式サポート/ブログ): 現物 メイカー **-0.02%**(マイナス手数料=受取)、テイカー **0.12%**。
  信用取引(2x, BTC/ETH/XRP): メイカー -0.02%、テイカー 0.12%、**建玉管理料 0.04%/日(年14.6%)を JST 0:00 時点の建玉に課す**(0:00前に決済すれば無料)。
  → 現物ではショートできない。「down」の仮想売買は信用取引前提で、72時間保有なら 0:00 JST を3回またぎ +0.12%。paper.py はこれを引いていない。
- 現在の paper.py: FEE 0.12%(片道), SLIPPAGE 0.05%(片道), 往復 0.34%, POSITION 10%, START 100万円。
- 現在の backtest(90日, 2026-06-11〜09-08, ema-cross-v1, 72h):
  BTC 予測1893件 的中49.87% / 売買29件 平均+0.219% sd 3.89 必要件数1214 最大DD 1.96%
  ETH 予測1880件 的中45.59% / 売買28件 平均+0.317% sd 6.50 必要件数1615 最大DD 2.00%
- run.py の建て値は「最後に閉じた足の終値」(base["c"])。実行は :05〜:20 UTC なので、その終値はもう存在しない価格。ticker は同じ run で取っている。
- 手仕舞い→同じ時刻に同方向で建て直す: backtest は next_free=i+H で i==next_free の足で再建玉(同じ価格で往復コスト0.34%だけ払う)。run.py も手仕舞い(3)→予測(4)→建てる(5)を同じ回で行うので同じ。
