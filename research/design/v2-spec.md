# v2 の仕様（事前登録）

書いた時刻: 2026-09-09 16:00 JST（この後に test 期間 2026-03-01〜2026-09-08 を1回だけ回す。回す前に決めた）

## 予測（strategy.MODEL = "tsmom-vote-v2"）
- 使う足: 閉じた1時間足の終値。最後の足を基準に、7日前・14日前・28日前（168・336・672本前）の終値との比を取る
- 3つのリターンの符号を多数決する。プラスが多ければ「上」、マイナスが多ければ「下」。3つのうちどれかが0で同数なら「見送り」
- 判定は72時間後の終値（いまと同じ）
- 自信（confidence）は出さない。理由に r7・r14・r28・票を書く
- パラメータ: 7・14・28日は文献（時系列モメンタムの1〜4週）から取り、train/valid では動かしていない

## 仮想売買（paper.RULE = "long-carry-v2"）
- 「上」のときだけ建てる。「下」は建てない（信用取引の建玉管理料と、4年で下の売買が負け続けた事実による）
- 1銘柄1玉・資金の10%・72時間後に見直す
- 72時間後、予測が同じ「上」なら閉じずに持ち越す（コストを払わない）。持ち越しても72時間ごとに1件として記録する
- 建て値・手仕舞い値は run の時点の気配（買いは ask、売りは bid）。加えて片道0.05%のすべりを引く
- 手数料は銘柄ごとの成行（bitbank API の値: btc 0.10%、eth 0.12%）
- ショートを持つ場合（v1 の玉の手仕舞いのみ）は JST 0:00 をまたぐたび 0.04% を引く

## 関門
- 銘柄ごとに、閉じた区間（72時間）の net% の t = 平均/標準偏差×√n
- 検査は n が 50・100・200・400 に達したときの4回だけ。t ≥ 2.36 で合格（4回の検査で偽陽性 約3%）
- 400件で合格しなければ、このモデルは終わり
- 検査の結果は data/gate.jsonl に追記する

## 比較の基準
- 常時ロング（同じ会計）を必ず横に置く
