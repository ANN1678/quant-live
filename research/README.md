# research/　予測モデルの見直し（2026-09-08〜09）

エンジンとは別の場所。**ここの結果は事前公開の記録ではない。**過去の足に後から当てはめたもの。
numpy と pandas を使う（エンジンは requests だけで動かす決まりなので、混ぜない）。

## 何をしたか

1. bitbank の1時間足を4年ぶん（2022-09-09〜2026-09-07）、6銘柄（btc・eth・xrp・sol・ltc・doge）取った。`fetch_history.py`
2. 検証台 `harness.py` を作り、`engine/backtest.py`（v1）の90日の数字を小数4桁まで再現できることを確かめた。`replicate_test.py`
3. v1（ema-cross-v1）を4年に当てた。**訓練期間も検証期間も平均はマイナス。**毎時の的中率は 47〜50%。`design/baseline.md`
4. 期間を分けた。訓練 2022-09〜2025-03／検証 2025-03〜2026-03／試験 2026-03〜2026-09。**試験は最後に1回だけ**回す決まり
5. 6つの角度で候補を作った（設計者6人が並列。試した変種の数も記録）。`candidates/` と `design/`
6. 候補ごとに3人が審査した（統計・実務・サイトの設計）。**6候補とも却下。**理由は `design/` の各ファイルと下の表
7. v2 の仕様を先に書き（`design/v2-spec.md`）、それから試験期間を1回だけ回した。`test_once.py`
8. エンジンを v2 に書き換え、`engine/sim.py` が検証台と同じ数字を出すことを確かめた（eth 4年 315件・平均 +0.5654%・t 1.744 で一致）

## 結果

| 角度 | 候補 | 検証期間（2025-03〜2026-03）の1件あたり平均 | 判定 |
|---|---|---|---|
| 日次モメンタム | tsmom-daily-v1（7/14/28日の多数決・H168・持ち越し） | 5銘柄 +0.79%（t 0.5）。上位3件を除くとマイナス | 却下 |
| 約定の工夫 | ema-long-limit-v1（v1の信号・ロングだけ・指値） | 5銘柄 −0.16%（成行 −0.38%） | 却下 |
| 銘柄横断 | breadth-long-v1（5銘柄全部が EMA48 の上ならロング） | 5銘柄 −1.54%（t −3.6） | 却下 |
| 暦・時間帯 | calendar-window-v1（22Z〜04Z だけロング） | 指値でも −0.05%。効果は2024年までで消えた | 却下 |
| ブレイクアウト | donchian-atr-v1（480本の高値安値の更新） | 5銘柄 −0.33%。訓練の t 2.9 は2024年の1年が作った | 却下 |
| 反転 | rsi24-oversold-v1（RSI<20 でロング） | 5銘柄 +5.4% だが 15件・9回の出来事。btc+eth だけなら +0.6%（t 0.2） | 審査未了（設計者自身が「運と区別できない」） |

運だけの基準線: ランダムな戦略60個の訓練での最良は t +1.39。それを検証で測ると t +0.01（`snooping_baseline`）。
**候補が訓練で t 1.4 を出しても運と区別がつかない。**

### v2 に置いたもの（証明ではなく仮説）

ロングだけ・持ち越し・区間会計で、常時ロングと並べた（`compare_v2.py`）。

| BTC+ETH | 件数 | 平均 | t | 常時ロング |
|---|---|---|---|---|
| 訓練 | 415 | +0.53% | 2.1 | +0.43%（t 2.2） |
| 検証 | 147 | +0.45% | 1.0 | +0.07%（t 0.2） |
| 試験（1回だけ） | 90 | +0.57% | 1.3 | +0.43%（t 1.0） |

xrp・ltc・doge では検証期間にマイナス。優位が銘柄をまたいで残る形ではない。
この表の手数料は両銘柄とも 0.12%（harness の既定）。engine は BTC 0.10% を使うので、BTC は1件あたり 0.04pt だけ良くなる。事前登録の数字はこのまま残す。
**それでも v2 にした理由**は、6角度の中で唯一、文献に根拠があって（時系列モメンタム）、パラメータを成績で寄せておらず、
検証と試験の両方で常時ロングを上回った（差は偶然の範囲）から。本番の関門で決める。

## エンジンの監査（`design/notes-2026-09-08.md` と下）

5つの観点（先読み・統計・コスト・信号・運用）で37件。重いもの:
- 関門が optional stopping（毎時見て最初に越えたら合格）。優位0でも偽陽性 30〜40%（モンテカルロ） → 4回の検査に変えた
- 最低件数が無く、プラスが2件並ぶだけで cleared → 同上
- 建玉管理料（ショート 0.04%/日）を引いていない → paper.py
- 建て値が「閉じた足の終値」＝存在しない価格（実勢と 0.1〜0.3% ずれ） → run 時点の気配
- 同方向の建て直しで往復コストを捨てる（90日 29件中 16件） → 持ち越し
- 10日窓の外に出た予測・玉が永久に判定されない → 判定待ちの時刻まで遡って取る
- 手仕舞いが冪等でなく、途中で落ちると trades.jsonl が二重になる → 区間 id で弾く
- git push が rebase しない → pull --rebase して3回まで試す
- bitbank の日付が UTC（JST で組むと 00〜09時に404） → 隣のセッションが 2026-09-09 06:41 に修正済み
